#Jogo da forca

Esse jogo faz parte do curso de Python do grandissíssimo professro Gustavo Guanabara.
Esse código só roda no terminal, sendo necessário fazer o download do script e
executá-lo para poder jogar.
No código há um espaço enorme entre a palavra-chave e o programa, portanto, quem for
aplicar o jogo precisa determinar a palavra-chave antes de apresentar o jogo para a pessoa
que for jogar.
